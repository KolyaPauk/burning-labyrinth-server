# Burning Labyrinth: сервер лидерборда

Node.js (без npm-зависимостей) + SQLite (`node:sqlite`). БД: `data/data.db`.

## Развёртывание на чистом Windows
1. Скопировать папку `Server` на ПК/ноутбук.
2. Запустить `setup.bat`. Скрипт скачает портативный Node.js в `runtime\` (если установленный Node не поддерживает `node:sqlite`: нужен 22.13+, 23.4+ или 24+), откроет порт в брандмауэре (запросит UAC) и покажет IP-адреса.
3. Запустить `start.bat`. При первом запуске он попросит придумать **пароль администратора** (минимум 6 символов). Без пароля сервер не стартует.
4. Админка: `http://localhost:3000/admin/`. Вход не требуется.
5. В UE в компоненте `Leaderboard Client` указать `Server URL` (например `http://192.168.1.10:3000`) и `Api Key` (значение `apiKey` из `config.json`).

Интернет нужен только на шаге 2. Для офлайн-развёртывания скопируйте папку `Server` вместе с готовой папкой `runtime`.
Желательно закрепить за сервером постоянный IP (резервирование в роутере).

## Конфиг и защита
- `config.json` (создаётся при первом старте): `{ "port": 3000, "apiKey": "..." }`. Ключ лежит в читаемом виде. Чтобы его сменить, поменяйте значение (или удалите поле и перезапустите сервер) и обновите ключ в UE. Если сменили порт, запустите `setup.bat -Port <порт>`.
- **API-ключ игры**: UE шлёт его в заголовке `X-Api-Key`. Без верного ключа `/api/results` отвечает `401`.
- **Пароль администратора** хранится в БД только в виде соленого хеша (scrypt), восстановить его нельзя. Он запрашивается при удалении результата. Остальные действия в админке (просмотр, сессии) пароля не требуют. Сменить пароль: `set-password.bat`.
- После 5 неверных паролей или ключей подряд IP блокируется на минуту (`429`), отдельно для пароля и для ключа.
- Трафик идёт по обычному HTTP, без шифрования. Ключ и пароль можно перехватить в одной сети, поэтому лучше использовать отдельную сеть для сервера и VR-устройства.

## Полный сброс
`reset-db.bat`: спрашивает пароль администратора и подтверждение `YES`, затем останавливает запущенный сервер и удаляет всю БД (результаты, сессии, пароль). Следующий `start.bat` начнёт с чистого листа и попросит новый пароль. `config.json` (порт и API-ключ) сохраняется. Сервер, запущенный до этого обновления, скрипт остановить не может: закройте его окно вручную.

## Как проводить сессию
1. В админке ввести имя игрока и нажать «Начать сессию».
2. Игрок проходит игру, UE отправляет результат.
3. Результат записывается под именем из сессии (присланный Nickname игнорируется), сессия закрывается. Для следующего игрока зарегистрируйте новую.

## API игры (заголовок `X-Api-Key` обязателен)
- `POST /api/results` с телом `{"Nickname","Score","Duration","BarrelsCollected"}`. Ответ `200 {"results":[{Nickname,Score,Duration,BarrelsCollected,Timestamp}, ...]}`. Без активной сессии `409 {"error", "results"}`.
- `GET /api/results`: тот же список (лучшие первые: Score по убыванию, Duration по возрастанию).
